# Security reporting

Do not post credentials, private datasets, model checkpoints, or exploitable vulnerability details in
public issues. Use GitHub's **Report a vulnerability** option in the repository Security tab. If it is
not available, use a private contact method listed on GitHub before sharing sensitive details.

Include the affected revision, impact, prerequisites, and a minimal reproduction using synthetic data.
Do not include unpublished training data or model weights. Security fixes target the default branch.
Dependency checks and automated tests do not constitute a security audit.
